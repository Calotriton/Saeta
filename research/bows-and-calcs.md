# Bow types and arrow calculations: research notes

Companion to `bows-and-calcs.json`. The JSON was generated by a script, and the script asserts that the generated wood charts reproduce the Manual del Club tables cell for cell.

> **Every result is a starting estimate.** The site should say so on every result screen: *"Estimación — confirma siempre con una prueba de flecha desnuda (bare shaft) y, si puedes, con un kit de prueba de spines."*

---

## 0. Conventions (aligned with the Manual del Club)

| Term | Definition used by the site | Source |
|---|---|---|
| **Draw length (apertura)** | At full draw, from the bottom of the nock groove to the **back** (outer face) of the bow at the arrow pass. | Manual del Club p.12: "des de dins del culatí fins al davant del cos de l'arc" |
| AMO/ATA draw length | To the pivot point (deepest part of the grip) **+ 1.75"**. On a normal handle the back of the bow sits about 1.75" in front of the pivot, so this is **in practice the same number** as the Manual's measurement. The site uses one definition: the Manual's. | ATA/AMO |
| **Arrow length** | From the bottom of the nock groove to the end of the shaft, not counting the point or insert. | Manual fig. 10, AMO |
| **Arrow length rule** | **Draw length + 1" (2.5 cm)**. Horse bows and children use +2". With broadheads, 3Rivers suggests +1–2". | Manual del Club p.12; 3Rivers |
| **Spine** | Deflection in thousandths of an inch with 1.94 lb (880 g) hung at the centre of a 28" span (ATA / ASTM F2031). A higher number means a more flexible shaft. Wood is spined in lb, e.g. 40-45#. | Manual del Club pp.4-5 |
| **Actual draw weight** | What the scale reads at the archer's own draw length. Bows are marked at 28". | Manual p.11; 3Rivers |
| Units | 1 lb = 453.6 g; 1" = 2.54 cm; 1 g = 15.43 gr. The Manual rounds to 15; the site calculates with 15.43. | Manual |

### Which way does centre-shot move the spine?

**The less centre-cut the bow, the weaker the arrow it needs.** On a longbow, self bow or a horse bow shot off the hand, the arrow points well to the side of the string line, so it has to flex more to get around the handle.

- 3Rivers' wood and aluminium charts put the longbow / self-bow column **10 lb heavier** than the recurve column for the same spine. For example, a 51-55 lb longbow takes the same spine as a 41-45 lb recurve.
- Tradgang bowyers and Outdoor Life give the same explanation.
- Longbows are also slower, which points the same way.
- A bow cut **past** centre, such as an ILF riser with a plunger, needs a **stiffer** arrow.
- Easton's *hunting* chart has a "longbow" column that seems to point the opposite way. It is inconsistent with every other source, so we do not use it.

### Horse bows

- With a thumb draw, a right-handed archer shoots from the **right** side of the bow, so archer's paradox is mirrored.
- Feathers are mandatory because the arrow passes over the hand.
- Arrows are usually longer. The suggested default is draw + 2", typically 29-32" for Hungarian bows and 32-36" for Mongolian bows.
- Siyahs make draw weight climb quickly past the rated draw.
- Sellers quote carbon spines close to the recurve chart: 30-35 lb → 600, 40-45 lb → 500, 50 lb → 400. That is why `spineAdj` is 0.

### LARP / bow combat

Kept only as a note (`styleNotes.larp`). The site should **not** calculate arrows meant to be shot at people. It should refer users to commercial safety arrows and the event's rules, which usually cap draw weight at about 25-30 lb.

## B. Draw length when it is unknown

1. **Preferred: measure it** with the graduated arrow (Manual fig. 9). Take 3 readings and average them. Uncertainty ±0.25".
2. **Wingspan:** `drawIn = wingspanCm / 2.5 / 2.54`, which is the same as `wingspanCm / 6.35`. This is the ATA fitting rule (wingspan / 2.5) with units kept consistent: wingspan in cm ÷ 2.5 gives cm, then convert to inches. Uncertainty ±1".
3. **Height:** `drawIn = heightCm / 6.35`, assuming wingspan ≈ height. There is a table for 110-200 cm in `drawLength.heightTable`. Uncertainty ±1.5". It agrees with the common height charts: 5'5" → about 26", 5'11" → about 28.4".
4. **Style adjustments** (added to methods 2 and 3):

   | Draw style and anchor | Adjustment |
   |---|---|
   | Mediterranean, under-chin (Olympic/barebow) | 0 |
   | Mediterranean, corner of mouth with canted bow (traditional) | −0.5" (range −0.5 to −1) |
   | To the ear (warbow) | +2" |
   | Thumb draw, cheek or ear anchor | +1" |
   | Thumb draw past the ear (gungdo, Mongolian) | +2.5" |

   These are heuristics.

5. Tell the user: *"start long, trim later"*.

## C. Draw weight

- **Actual weight at the archer's draw:** `actual = marked × (1 + perInchPct × (draw − markedAt))`.
  - The percentage form scales correctly from kids' bows to warbows.
  - The values come from the linear-spring approximation (1 / (28 − 1.75 − brace) ≈ 5 %/in), with extra for bows that stack (self bows and horse bows, about 6 %).
  - At about 45 lb this gives 2-2.7 lb/in, which matches 3Rivers' "2-3# per inch".
  - A simple fixed lb/in table is also included (`perInchAdjust`).
  - Marked weight can be off by ±2 lb (3Rivers).
  - Warbows are often rated at 30" or 32", and youth bows at 24-26". The site should let the user change `markedAt`.
- **Measuring:** use an archery or luggage scale on the nocking point at full draw (Manual figs 7-8), and repeat 3 times.
- **Starting weights by profile:** compiled from CHN Archery, Archery360, Lancaster and learn-archery. Sources disagree, so the ranges in `drawWeight.profiles` lean conservative:

  | Profile | lb |
  |---|---|
  | Child 6-10 | 10-15 |
  | Child 11-13 | 12-20 |
  | Teen | 16-26 |
  | Adult woman, beginner | 18-26 |
  | Adult man, beginner | 22-32 |
  | Older or less strong beginner | 15-24 |
  | Intermediate | 28-40 |
  | Experienced 3D | 35-50 |
  | Hunting | 45-60 |
  | Warbow | 80-160 |

  Practical test: hold full draw for 5-6 s without shaking, and shoot 60 arrows without pain.

## D. Spine algorithms

### Wood (lb). Reproduces the Manual del Club Annex I exactly

```
W_eff     = W_actual + pointAdjWood + bowType.spineAdj + stringAdj
spineLbs  = W_eff + 5 × (arrowLengthIn − 28)
bandLow   = 5 × floor((spineLbs − 0.5) / 5)     → "bandLow-(bandLow+5)"
```

- **`pointAdjWood`** is interpolated from the chart columns: 100 → −5, 125 → 0, 145 → +5, 160 → +10, 190 → +15. That is roughly 5 lb per 20-25 gr.
- **`stringAdj`**: Dacron 0. Fast Flight and other HMPE strings +5 (3Rivers chart header). A forum post says +15 when going from B-50 to FF; we keep the published +5.
- **Brace height (fistmele)** is qualitative only:
  - Manual Table 2: more brace height → less speed and more stability.
  - Most traditional archers say raising brace height makes the arrow act stiffer. One quoted Easton text says the opposite.
  - So it is shown as fine-tuning advice, not as a number.
- **Validation:** asserted in the generator script.
  - "English Longbow / Spine Guide" (Manual p.47; columns are *draw* lengths 25-31"): reproduced cell by cell using `spineAdj = −10` and arrow = draw + 1. The highlighted cell, 40-45# @30" → 45/50, matches.
  - Manual p.46 (the 3Rivers wood chart, recurve and longbow sides, points 100-190, arrows 23-32"): reproduced. It works as a diagonal index, `cell = row + (L − 28)`.
- **Charts in the JSON:** `spine.wood.charts` contains:
  - `manualEnglishLongbow`
  - `manual3RiversWood`
  - generated `recurve` and `longbow` charts, rows 20-80 lb × arrow 25-32"
- **Diameter guidance** follows the Manual's calibres (5/16 thin, 11/32 medium, 23/64 thick) with indicative spine ranges.

### Carbon (ATA spine number)

```
effLbs = W_actual + 5×(L − 28) + 3×(point − 125)/25 + bowType.spineAdj + stringAdj
spine  = log-interpolate(curve, effLbs) → snap to nearest group
         (show "a/b" when within ±2 % of the log-midpoint of two groups)
```

- **Point adjustment:** 3 lb per 25 gr, as on the Easton target and hunting charts. 3Rivers' carbon columns step by about 3 lb per 25 gr too.
- **Length:** each 1" moves one row (about 5 lb) on both Easton and 3Rivers.
- **Curve:** sits between two sources:
  - **Easton Target chart**: recurve finger release with carbon limbs. Easton says wood/glass limbs are −5 lb, and 125 gr is +3, so a traditional recurve at W is about Easton W − 2.
  - **3Rivers carbon chart**: at 28"/125 gr it gives 29-33 → 600, 34-48 → 500, 49-63 → 400, 64-75 → 340, 76+ → 300. Below 50 lb it is about one group stiffer than Easton.
- **Resulting bands** (`spine.carbon.chart`):

  | Effective lb | Spine |
  |---|---|
  | ≤17 | 1500 |
  | 18-20 | 1200 |
  | 21-23 | 1000 |
  | 24-26 | 900 |
  | 27-29 | 800 |
  | 30-35 | 700 |
  | 36-42 | 600 |
  | 43-51 | 500 |
  | 52-62 | 400 |
  | 63-72 | 340 |
  | 73-85 | 300 |
  | 86+ | 250 |

  Around 40-45 lb at 28" the result is "600/500", which honestly reflects that the sources disagree.
- **Between two groups:** Easton advises the weaker spine for recurves. Bare-shaft testing settles it.
- **Longbows:** we use a consistent −10. 3Rivers' carbon longbow column implies about −15 to −18.
- **Typical GPI by spine** is included as a fallback. Always prefer the maker's published GPI (Manual Form. 4).
- **Conversion:** static equivalent only, `woodLbs ≈ 31500 / ATA spine`. It comes from scaling the 26"/2 lb wood test to the 28"/1.94 lb test and matches a published figure (0.487 → 64.7#). The site must **not** pick spine from this conversion, because lighter carbon behaves stiffer in flight.

### Aluminium

- Uses the 3Rivers letter chart, which is one-dimensional in effective weight using the wood-style point adjustment.
- Effective weight 26-30 → A (1716), up to 86-95 → N (2317). Letters map to Easton sizes (`letters`).
- GPI is calculated from the size code: `π(OD−wall)·wall` × 7075 alloy density. These are approximate, within a few %.
- Aluminium is now uncommon for traditional bows. Keep it as a secondary option.

### Fibreglass

Makers use their own numbering. The site uses guidance by actual draw weight:

| Actual weight | Guidance |
|---|---|
| ≤15 lb | 6 mm fibreglass |
| 15-25 lb | 5/16" tubular fibreglass (or carbon 1000-1500 / aluminium 1616-1716) |
| 25-30 lb | Thick-walled fibreglass only; better to move to carbon or wood |
| >30 lb | Not recommended |

Safety note: fibreglass splinters when it breaks.

## E. Weight, balance and speed

- **Shaft** = length × GPI (Manual Form. 4).
- **Wood GPI from density:** `ρ × π/4 × d² × 2.54 × 15.43`. With POC cedar (ρ ≈ 0.47) that gives 9.1 / 11.0 / 12.1 gr/in for 5/16 / 11/32 / 23/64. This matches the usual 300-400 gr per 32" cedar shaft. The species table includes cedar, spruce, pine, Douglas fir, poplar, birch, ash and bamboo, with ranges.
- **Feathers:** turkey shield/parabolic ≈ 0.6 gr/in. The verified figure is Trueflight 4" shield = 2.3 gr. Add about 1 gr of glue per feather. A 3 × 5" fletch ≈ 12 gr. Vanes ≈ 2.5 gr/in.
- **Nocks:** self nock 0; glue-on 8/10/12 gr (5/16, 11/32, 23/64); press-fit ≈ 7; pin + nock ≈ 12.
- **Inserts:** aluminium ≈ 16; brass 25-100.
- **Wraps** ≈ 1.5 gr/in; cresting 3-10 gr.
- **Point weight (Manual Form. 1-2 / 5-6):** `(shaft + nock + fletching [+ wrap]) / 3` for wood and `/ 2.5` for carbon.
  - We read the Manual's "pes total" as **excluding the point**. Form. 5's text says it needs the shaft, the number of feathers and their weight, and the nock type; it does not mention the point.
  - If the point were included, the formula would become rest / 2 (wood) and rest / 1.5 (carbon). **Ask the club to confirm.**
- **Minimum weight (Manual Form. 3):** `draw lb × 8-9 gr`.
- **GPP bands:**

  | GPP | Band |
  |---|---|
  | <6 | danger |
  | 6-8 | light (ILF/target; check maker) |
  | 8-10 | standard (Manual) |
  | 10-12 | heavy (hunting, self bows) |
  | 12+ | warbow / primitive |

- **FOC:** `(B − L/2) / L × 100`, where L = nock throat to end of shaft (AMO convention, Ashby) and B = balance point from the nock throat.
  - **From components:** `B = Σ m·x / Σ m`, with positions: shaft at L/2, point at L+0.3", insert at L−0.5", nock at 0.3", fletch at 1.25 + len/2, wrap at 0.25 + len/2.
  - **Worked example:** 28.5" × 11 gpi cedar + 125 gr + 10 gr nock + 3 × 5" feathers → **460 gr, FOC 11.8 %**.
  - **Targets:**

    | Use | FOC |
    |---|---|
    | Target / traditional 3D | 7-12 % |
    | 3D (Ashby) | 6-12 % |
    | FITA (Ashby) | 11-16 % |
    | Hunting (Easton) | 10-15 % |
    | Ashby EFOC (hunting) | ≥19 % |

  - <5 % or negative FOC means an unstable arrow.
  - Note for users: more point weight raises FOC but makes the arrow act weaker.
- **Speed (rough, ±10-15 %):** a virtual-mass (Hickman) model.

  ```
  E   = storageFactor × W × (draw − 1.75 − brace) / 12      [ft·lb]
  η   = hysteresis × m / (m + virtualMass)
  v   = √(450240 · η · E / m)                               [fps]
  KE  = m·v² / 450240                                        [ft·lb]
  p   = m·v / 225218                                         [slug·ft/s]
  ```

  Parameters are set per bow type. Sanity checks:

  | Setup | Result |
  |---|---|
  | 50 lb recurve, 500 gr | 172 fps |
  | English longbow, same arrow | 159 fps |
  | Self bow, 550 gr | 146 fps |
  | 38 lb ILF, 300 gr | 185 fps |
  | 15 lb kids' bow | 88 fps |

  These match typical chronograph reports for traditional bows. Show results as "≈" and always with the caveat.

## Caveats to surface in the UI

1. Charts are **starting points**. 3Rivers itself says "only a reference point… Test kits are highly recommended". Bare-shaft test and adjust (point weight, length, brace height) before buying.
2. Carbon charts disagree by up to one spine group between brands. Use the maker's chart for the specific shaft when one exists.
3. Wood shafts vary in both spine and weight. Weigh and match them within ±10 gr, and spine-test them if possible.
4. Self bows, warbows and horse bows: follow the bowyer's minimum arrow weight. Never dry-fire. Never shoot an arrow below about 6 gpp in any bow.
5. Draw-length and draw-weight estimates carry about ±1" and ±2-3 lb of error. Measured values always win.
6. Children: longer arrows (draw + 2") and low draw weights. Supervision is required.
